# How six colleges say they weigh admission factors (Common Data Set section C7)

Source: each college's own Common Data Set, as extracted by collegedata.fyi (https://www.collegedata.fyi). Data years differ per college and are shown in each section.
Fetched: 2026-10-10. Extraction caveat: values were read from PDFs/spreadsheets by software; check the college's own file (URL in each section) before quoting to a family.
What this document can support: what a college SAYS about each factor. It cannot support how much a factor changes any decision.

## UCLA: admission factors, Common Data Set 2025-26

Source file: https://apb.ucla.edu/file/d1ab04b3-ee89-4cf2-9124-8dc0471b5e5a  |  Extract: https://www.collegedata.fyi/schools/ucla/2025-26/cds.csv  |  Data year: 2025-26

- UCLA rates these as 'Very Important': Rigor of secondary school record; Academic GPA; Application essay.
- UCLA rates these as 'Important': Extracurricular activities; Talent or ability; Character and personal qualities; Volunteer work; Work experience.
- UCLA rates these as 'Considered': First generation; Geographical residence; State residency.
- UCLA rates these as 'Not Considered': Class rank; Standardized test scores; Recommendations; Interview; Alumni relation; Religious affiliation; Level of applicant interest.
